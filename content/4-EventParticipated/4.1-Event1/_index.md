# Event Report: Buildrathon Kickoff: Code the Future with CMC Global

### Event information

- **Date and time:** September 26, 2026, 9:00 a.m.–11:20 a.m.
- **Location:** Bitexco Financial Tower, Ho Chi Minh City
- **Role:** Attendee
- **Event page:** [Buildrathon Kickoff: Code the Future with CMC Global](https://luma.com/8fe9vvps)

### Overview

Hosted by CMC Global, the kickoff introduced the Buildathon challenge, its objectives and judging criteria, and the use of AWS Cloud and generative AI to build modern AI agents. The program included an ice-breaking session, a talkshow on careers in Cloud and AI, and a question-and-answer session.

During the event, I listened to the presentations and asked Truong Bui, a Tech Lead at CMC Global, questions during the discussion. One presentation illustrated an AI-enabled Slack bot architecture, with components including WebSocket, a response gate, Claude Code, an internal API, and a database. The event gave me an opportunity to hear practitioners discuss cloud and AI work and learn how they explain an architecture through its individual components. I also received a gift at the event.

### Note on the scheduled AI Agent Challenge

The Luma event page listed a hands-on AI Agent Challenge, but this activity did not take place at the event I attended. This report describes the sessions and activities that actually occurred; I did not build or test an AI agent at the event.
