# Event Report: Buildrathon Kickoff: Code the Future with CMC Global

### Event information

- **Date:** September 26, 2026
- **Published start time:** 9:00 a.m. (Vietnam time, UTC+7)
- **Location:** Bitexco Financial Tower, Ho Chi Minh City
- **Role:** Attendee
- **Event page:** [Buildrathon Kickoff: Code the Future with CMC Global](https://luma.com/8fe9vvps)

### Event objectives

- Introduce the Buildrathon program and the expectations for its participants.
- Connect cloud and AI learning with examples shared by industry practitioners.
- Give attendees an opportunity to ask questions and discuss the presentations.

### Speakers

| Order | Speaker | Position | Contribution to the event |
| --- | --- | --- | --- |
| 1 | [Nguyễn Gia Hưng](https://www.linkedin.com/in/jotaguy/) | Head of Solutions Architect, AWS Vietnam and Cambodia | Opened the program, introduced Buildrathon, and explained its purpose and direction. |
| 2 | [Nhật Trường Bui (Truong Bui)](https://www.linkedin.com/in/dominicbui0000/) | Tech Lead, CMC Global | Followed with a technical presentation, including an example AI-enabled Slack bot architecture, and answered questions. |

The opening presentation established the context for the program. The subsequent session brought the discussion to a concrete software architecture. This sequence helped connect the program introduction with an example from technical practice.

### Key highlights

#### 1. Program introduction and Buildrathon orientation

Nguyễn Gia Hưng introduced the program and the Buildrathon challenge. The kickoff provided context for the learning journey and the outcomes participants would work toward. The [published event description](https://luma.com/8fe9vvps) also outlined the challenge's objectives and judging criteria.

The presentation materials included an overview of AWS's presence in Vietnam, organized around investment in local talent, infrastructure, and future skills. This gave the opening session a broader context for developing cloud and AI capabilities.

#### 2. A practical example: an AI-enabled Slack bot

The technical presentation showed a diagram labeled **Market Slack Bot**. The session explained an architecture through its connected components:

| Component shown on the slide | Detail illustrated in the diagram |
| --- | --- |
| Slack | Requests associated with mentions, direct messages, and active threads. |
| Socket Mode / WebSocket | The connection between Slack and the bot workflow. |
| Response gate | A response-control component positioned before Claude Code. |
| Claude Code | A processing component with output labeled `print · JSON`. |
| `SOUL.md` and Memory | Voice and scope configuration, alongside thread context. |
| Bot schedule, internal API, and cron + database | Planned turns, application-owned jobs, and storage associated with memory and scheduled tasks. |

The diagram brought attention to several parts of an AI application: the channel that receives requests, response handling, context, and scheduled work. These were useful details to capture when reviewing the example after the event.

#### 3. Questions and direct exchange with the speaker

After listening to the presentations, I asked Nhật Trường Bui questions during the discussion. This was my direct contribution to the session and an opportunity to exchange with a Tech Lead from CMC Global.

### Key takeaways

- The program introduction clarified the purpose of the kickoff and the context of Buildrathon.
- The Slack bot example helped me organize the architecture into request handling, processing, context, and scheduled tasks.
- Asking questions was a way to participate actively and clarify points from a technical presentation.

### Applying the learning

Possible follow-up activities include revisiting the photographed diagram, mapping its components to a simple architecture outline, and exploring how conversation context and scheduled tasks could be represented in a learning project. These are directions for further study, not work completed during the event.

### Event experience

I attended as a listener, followed the program introduction and technical presentation, asked Nhật Trường Bui questions, and received a gift. The accompanying photos record the presentations and gift presentation.

The registration page listed a hands-on AI Agent Challenge, but it was not held at the event I attended. My participation therefore consisted of listening and asking questions; I did not build or test an AI agent during the event.
